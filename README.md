# saimsunny.net

## Write an article

1. Go to the `_posts` folder on GitHub and click **Add file > Create new file**.
2. Name it like this: `2026-11-15-my-title.md` (date first, then the title with dashes).
3. Paste this at the top, then write below it:

```
---
title: My title
summary: One short line about the article.
tag: Building
image: /images/my-photo.jpg
---

Your text here. Use **bold**, ## Headings and - lists.
```

4. Click **Commit changes**. The article is online in about a minute.

`summary`, `tag` and `image` are optional. To add a photo: open the `images` folder,
click **Add file > Upload files**, then use `/images/your-file.jpg`.

## Change the videos

Edit `videos.js`. Each video is one line in a group (Client work, Films and vlogs,
Events, Other projects). Paste a YouTube, Instagram or Facebook link.
